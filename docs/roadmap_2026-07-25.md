# Research roadmap — 2026-07-25

Supersedes the ad-hoc queue in `docs/strategy_program.md` §Live task queue. This
document is the sequence; the strategy program stays the authority on what the
evidence currently says.

Nothing here authorizes a deployment, a runtime change, or real money.

---

## 0. The problem, stated precisely

Three measurements from 2026-07-24/25 define the situation. They are not
opinions and they constrain everything below.

**0.1 — No signal survives multiple-testing correction.**
Roughly 44 mechanisms have been tested in this program. The Bonferroni threshold
at α=0.05 is **t = 3.25**. Our best signals, priced at the measured cost, are:

| signal | t | Sharpe |
| --- | ---: | ---: |
| premium_diff (24h, Bybit) | 2.06 | 0.66 |
| momentum continuation (1w) | 1.65 | 0.73 |
| BTC-gated short book | 1.30 | 0.98 |

None clears 3.25. **We do not currently have a validated edge.** Every number in
this repository that looks better than this was produced at a 4 bp cost
assumption that the forward journal has disproven.

**0.2 — Execution work cannot rescue it.**
Measured round trip is 15.56 bp; a perfect passive book floors at 5.40 bp. That
moves the registered blend from Sharpe 0.69 to **1.17** at the theoretical
maximum, and entries are only 50% of the fee bill so ~0.95 is the realistic
ceiling. Execution is a **multiplier, not a source**. Optimising it before an
edge exists is polishing a number that is not yet established.

**0.3 — Forward-only grading cannot resolve this in useful time.**
Since `t = Sharpe × √years`:

| true Sharpe | years to t=2 | years to t=3 |
| ---: | ---: | ---: |
| 0.7 | 8.2 | 18.4 |
| 1.0 | 4.0 | 9.0 |
| 1.3 | 2.4 | 5.3 |
| 1.6 | 1.6 | 3.5 |
| 2.0 | 1.0 | 2.2 |

A Sharpe-1.0 strategy needs four years of forward data to reach even t=2. The
forward record restarted 2026-07-22 and currently holds **1 round trip**.

### What follows from this

The binding constraint is **statistical, not computational**. Running more
sweeps makes it strictly worse: each new mechanism raises the correction
threshold and buys a t≈2 result that means nothing. There are only three real
escapes, and the roadmap is built from them:

1. **Raise the effect size** — find something with Sharpe > 1.6, which proves in
   under two years instead of eight.
2. **Multiply the sample without waiting** — independent replication across
   venues, eras, and asset classes converts one weak result into several
   corroborating ones.
3. **Shrink the search space** — few hypotheses with strong structural priors,
   tested deeply, instead of wide sweeps tested shallowly.

**The discipline shift this roadmap encodes: stop searching wide, start testing
deep.**

## 1. What makes an experiment count here

Every item below is an A/B with these properties. An experiment that lacks any
of them produces a diagnostic, not evidence.

- **Paired arms.** Two arms identical in every respect except the one variable.
  A backtest compared against a different backtest is not a control.
- **Deterministic allocation.** Assignment by signal-hash parity, fixed at signal
  time, reproducible from the journal. This is already the house pattern
  (`passive_execution_experiment_2026-07-20.md`).
- **Pre-declared primary metric and sample size**, the sample size computed from
  the power table in §0.3 for the effect size claimed.
- **No peeking** at the primary metric before the target. Operational health may
  be inspected at any time.
- **Written kill criteria** before the run starts.
- **Measured cost only** — 15.56 bp round trip, or realised journal fees where
  available. No arm may be reported at a modelled cost.
- **Registered by commit.** Per `docs/governance.md`, the commit is the
  registration.

| # | Task | Why it gates everything |
| --- | --- | --- |

| 0.3 | **Reconcile the CONTINUOUS backtest against forward reality.** Backtest says Sharpe 2.74, max drawdown 1.29%. Forward lost money. Explain the gap. | This is the single most informative unexplained fact in the system. |
| 0.4 | Resolve whether exit fills are native-stop triggers or owner reduce-only orders. | Decides whether exit-side cost is addressable at all (§15.2). |

**Gate 0.** If 0.3 cannot be explained, **every historical reconstruction in this
repository is suspect** and the program restarts on forward data only. That is a
real possible outcome and it should be stated before the work, not after.

## 3. Phase 1 — Re-screen honestly, once

One pass, not a sweep. Re-run only the mechanisms that have already survived

- Signals: premium_diff, momentum continuation, BTC-gated short, funding carry

**Gate 1.** If nothing clears 3.25 — which is the expected outcome — **do not run

## 4. Phase 2 — The three escapes, run as A/Bs

These run in parallel. Each attacks the power problem from a different side.

### 2A — Replication instead of waiting *(attacks: sample size)*

Two venues are two partly-independent samples. A signal confirmed on both earns
roughly √2 the effective t immediately, at zero waiting cost — and venue
divergence has already killed several ideas in this program, so it discriminates.

- **Arm A**: signal on Bybit. **Arm B**: the identical signal on Binance,
  independently costed with Binance's own fee schedule and funding.
- **Primary metric**: sign agreement and effect-size ratio across venues.
- **Kill**: opposite sign on either venue, or a ratio outside [0.5, 2.0].
- **Cost**: cheap — the cross-venue panel already holds both.

### 2B — Regime conditioning *(attacks: effect size)*

The largest conditional effect measured anywhere in this program: the BTC
30-day uptrend gate takes the reconstructed short book from **+1.29 bp/day
ungated to +41.09 gated**, while *improving* the tail (worst day −17.8%, loss
concentration 7.7%). If regime conditioning generalises across books rather than
being specific to that one, it is worth more than any individual signal.

- **Arm A**: each surviving book, ungated. **Arm B**: identical book, BTC-regime
  gated. Same signal, same universe, same sizing.
- **Primary metric**: Sharpe and worst-1% of days, per book.
- **Powered for**: the observed effect is large enough to test on existing
  history; the forward commit follows only if it replicates in 2A.
- **Kill**: gate improves fewer than half the books tested, or the improvement
  disappears under 2A replication.
- **Watch for**: the gate cuts sample by ~60%. A conditioner that only looks
  good because it trades less is a volatility reduction, not alpha — compare on
  Sharpe, never on total return.

### 2C — Structure *(attacks: tail, already registered)*

`docs/preregistration/basket_short_tail_experiment_2026-07-25.md`. Arm A
idiosyncratic short leg, arm B equal-notional basket short. 60 round trips per
arm, tail statistics primary. Runs on paper, unchanged.

**The honest expectation is that Phases 0 and 1 produce mostly negative results.**
That is the point. The current position is not "we have a strategy that needs
tuning" — it is "we have no validated edge, priced honestly, and a measurement
apparatus that until yesterday was reporting numbers at a quarter of true cost."
Establishing that cleanly is worth more than another sweep.

The two things most likely to change the picture are **2B** (a conditioner large
enough to lift a book above the noise) and **3.1** (an input nobody in this
repository has ever had). Everything else is bookkeeping — necessary, but not
where the answer comes from.

## 8. Phase 5 — Widen the sample, then look outward

**Do not start this until Phases 0–4 have run and reported.** It is sequenced
last deliberately: it is the most open-ended work in the plan, and it is only
worth doing once the instruments are repaired and the honest re-screen is done.

### 5A — Tune gates and filters for *t*, not for mean

Every filter in this system was chosen to raise the mean. But `t = effect × √n`,
so a filter that raises the mean while cutting the sample can *lower* the
evidence it produces. Break-even is unforgiving:

| sample kept | effect multiple needed just to hold t constant |
| ---: | ---: |
| 75% | ×1.15 |
| 50% | ×1.41 |
| 25% | ×2.00 |

The BTC-gate result is the live example: it multiplies the mean **32×**
(1.29 → 41.09 bp/day) but keeps only 39% of days, so it lands at t 1.30 rather
than something decisive. A slightly looser gate that keeps 70% of days at half
the effect would score *better*.

**The work**: for each gate and filter in the surviving books — regime gate
threshold, liquidity/turnover cut, universe size, listing-age bound, entry
level and timing, decile cut — sweep the strictness and select on **t**, not on
mean or Sharpe.

This is a one-dimensional sensitivity on an already-selected book, not a new
mechanism hunt, so it does not carry the program-wide multiple-testing cost of
§0.1. It does carry its own, over the grid: **report the entire curve, never the
best cell**, and correct for the grid size. A t that peaks sharply at one
setting and collapses either side is overfitting; a broad plateau is a real
parameter.

Expected payoff: this is the cheapest available route from t≈1.3 to t≈2, because
it buys sample rather than waiting for it.

### 5B — Lower the entry bar to raise the trade count

Related and separate: the books currently trade rarely (LONG: 292 trades in 5.5
years). Entry conditions that are strict for economic reasons should stay; those
that are strict by inheritance should be loosened and measured. Same rule —
select on t, report the whole curve.

**Constraint**: more trades at 15.56 bp round trip costs more in fees. Every
loosening must be evaluated net, and a trade-count increase that does not raise
t is just fee expenditure.

### 5C — Source hypotheses from outside this repository

The 24h-display rollover came from a practitioner write-up (robot james, *"a
truly idiotic crypto trade"*), and although it did not pay, it was a genuinely
novel mechanism that this program would never have generated internally — and it
validated that the panel detects a known-shape effect where one should exist.
That is worth repeating deliberately.

**Where to look**: practitioner substacks and blogs (Robot Wealth and similar),
crypto-microstructure academic work, exchange research and post-mortems,
liquidation-cascade literature, and public quant community writing. Prefer
sources that describe a *mechanism* — why the effect exists and who is on the
other side — over sources that publish a backtest.

**Discipline that applies unchanged**: an external idea is a hypothesis, not a
shortcut. It gets the same 15.56 bp cost basis, the same A/B structure, the same
t ≥ 3.25 threshold, and it counts against the multiple-testing budget like any
other mechanism. Import few, chosen for mechanism plausibility, and test them
deeply.

**Bias to correct for**: published ideas are survivorship-selected — people write
up what worked for them, on their venue, in their era. Test the mechanism, not
the parameters they quote, and check it on both venues before believing it.

## 9. The architecture is the deeper problem

Added 2026-07-25 after an operator challenge: three separately hand-tuned
sleeves would not survive review at a serious research shop. That is correct,
and this repository's own audit already contains the proof.

### 9.1 The evidence

> "Fixed-capital **barebones** books were approximately **−3.23% LONG** and
> **−20.23% CONTINUOUS** after modeled costs and funding."
> — `docs/strategy_program.md`, Strategy Overhaul V2 audit

**Strip the tuning and both deployed sleeves lose money.** Every positive number
either sleeve has ever produced comes from the parameter layer sitting on top of
a negative base. Supporting facts, all already on record:

- **29 families and 150+ configurations** were tested over the same hourly
  entry/exit/sizing surface. That search cost was never charged against any
  result.
- `LongV11aDivWeekendVol` — the name encodes at least eleven prior iterations on
  the same data, plus a weekend-volatility tilt chosen after the fact.
- `continuous_ensemble_v2` is `turn3p3 + turn4p3 + turn4p5`: three adjacent cells
  of a turnover-parameter sweep, averaged. Averaging neighbours in a grid is
  smoothing, not diversification — it produces one signal with a hidden
  selection step, not three independent ones.
- Named constants throughout — `age300`, `ff6`, `drop_all_4`, `volup125` — each
  a free parameter fixed by search rather than by economics.
- Priced honestly (§0.1), nothing in the system clears t = 3.25.

### 9.2 What this explains

The signature is textbook: **barebones loses → tuned wins → forward loses.** The
middle step is fitting the historical sample; the third is the out-of-sample test
returning the verdict.

This is now the **leading hypothesis for Gate 0.3**. The CONTINUOUS backtest
reports Sharpe 2.74 at a 1.29% drawdown while forward lost money, and the
simplest explanation is not a funding bug — it is that the reconstruction
inherits the fit and the forward record does not. Test that hypothesis first: it
is cheaper than every alternative and it would explain the whole gap.

### 9.3 The standing test

Adopt the barebones comparison as a permanent gate rather than a one-off audit
finding:

> **No signal is a candidate unless its untuned form beats costs.**

Untuned means: no regime gate, no age filter, no concurrency cap, no cooldown, no
weekend tilt, no ensemble averaging — the raw mechanism, sized flat, at 15.56 bp.
A signal that only works dressed is a fit, and the dressing is where the search
cost hides.

### 9.4 What the structure should be instead

The problem is not that there are several books. Multiple weakly-correlated
alphas is correct practice. The problem is **three hand-tuned products, each
with its own private parameter set and its own unaccounted search**, with no
layer above them.

The shape to move toward:

1. **One causal feature library** — PIT-correct, shared, tested once.
2. **Few signals, each with a stated mechanism** — why the effect exists and who
   is on the other side. Parameter variants of one idea count as one signal.
3. **One portfolio construction layer** over all signals — a single risk model,
   sizing, netting, and correlation handling. Not per-sleeve sizing plus a BTC
   hedge bolted on.
4. **One execution layer** — chase-then-cross, applied uniformly.
5. **Parameters set by economics or held fixed**, and every search that *was*
   run counted against the significance threshold.

### 9.5 How this changes the plan

It does not reorder Phases 0–4; it changes what a "pass" means.

- **Phase 0** gains the barebones reconstruction as the first thing to try on
  Gate 0.3.
- **Phase 1** re-screens **untuned** forms first. A mechanism that fails
  barebones does not proceed to have gates added to it.
- **Phase 2B** (regime conditioning) is now explicitly a test of whether gating
  is *real structure or the fitting mechanism itself*. The BTC gate turning
  +1.29 into +41.09 bp/day is exactly what an overfit conditioner looks like as
  well as what a real one looks like — cross-venue replication (2A) is what
  separates them, so 2B must not be adopted without 2A.
- **Phase 5A** is unchanged in method but reframed: tuning for `t` is legitimate
  *only* on a signal that already passed barebones. Otherwise it is the same
  disease with a better metric.
