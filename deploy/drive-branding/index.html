liquidity

A private backup utility for Liquidity Migration.

The operator uses this tool to copy trading-engine state and recorded market data from the operator's server to the operator's Google Drive. Those copies support recovery after a server failure and preserve market-data archives.

What the app does

  • Copies runtime logs, trade and order records, worker checkpoints, and configuration needed for recovery.
  • Uploads completed market-data archives and checks the uploaded files against the local copies.
  • Keeps the latest state backup and cleans up older backup history according to the operator's retention setting.

Google Drive access

The app requests drive.file access to create and manage its backup files, and files explicitly made available to the app. It does not request access to all files in the Google Drive account. Authorization is performed by the operator through Google's consent screen.

Who uses it

This is an operator-only tool, with no public account registration or backup service. This website explains the app; it does not sign users in or receive backup data.

Read the privacy policy for the data involved, retention, and access controls.
